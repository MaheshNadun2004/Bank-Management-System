# 🏦 Bank Management System

A desktop-based Bank Management System developed using **C#, .NET Windows Forms, SQL Server, and ADO.NET**. This application helps manage customer information and bank accounts through a simple graphical user interface.

## 📌 Features

- 🔐 User Authentication
- 👤 Customer Management
- 💳 Bank Account Management
- 🔍 Search Customer and Account Details
- ✏️ Update Existing Records
- 🗑️ Delete Records
- 🗄️ SQL Server Database Integration
- ✅ Input Validation and Error Handling

## 🛠️ Technologies Used

- **Language:** C#
- **Framework:** .NET Windows Forms
- **Database:** Microsoft SQL Server
- **Database Connectivity:** ADO.NET
- **Concepts:** Object-Oriented Programming (OOP), CRUD Operations

## ⚙️ Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/MaheshNadun2004/Bank-Management-System.git
   ```

2. Open the solution file (`.sln`) in Visual Studio.
3. Configure the SQL Server database connection string.
4. Create or restore the required database and tables.
5. Build and run the application.

To develop a desktop application that simplifies customer and bank account management while demonstrating practical skills in C# programming, database management, and desktop application development.
